## Summary

Current VBA exports and the auxiliary build script implement substantial portions of the specified treport subsystem (F1-F7 logic, F8 tooling), but multiple spec-critical behaviors and deployment/runtime outcomes remain **unverified** due to binary workbook opacity, missing runtime evidence, and environment-dependent Excel/Power Query behavior. Where spec and observed behavior/history diverge (notably file resolution scope/ambiguity and collision scoping history), explicit alignment decisions and runtime verification are required.

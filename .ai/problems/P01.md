#  3. Группировка строк Excel на основе параметра `group_rows` в в data_files.

Необходимо реализовать автоматическую группировку строк Excel после вставки каждого subreport на лист.

## 1. Общий принцип

Каждая запись в `data_files` представляет собой отдельный небольшой отчет (`subreport`) — диапазон ячеек, который копируется из исходных данных и вставляется на целевой лист Excel.

После вставки каждого subreport необходимо выполнить группировку строк на основе его параметров.

У вставляемого диапазона имеются следующие параметры:

- `paste_row` — номер строки, начиная с которой вставляется диапазон;
- `paste_col` — номер столбца, начиная с которого вставляется диапазон;
- `width` — ширина вставляемого диапазона в столбцах;
- `height` — высота вставляемого диапазона в строках;
- `group_rows` — числовой параметр, определяющий номер столбца внутри вставляемого диапазона, по которому необходимо определять строки для группировки.

Для `group_rows` использовать нумерацию столбцов, начиная с 1.

## 2. Критерий группировки

Группировка выполняется на основании цвета заливки ячеек в столбце c номером `group_rows`.

**Группируемыми считаются строки, у которых ячейка в указанном столбце имеет:**
- белый цвет заливки;
- либо заливка отсутствует (цвет по умолчанию).

Строки с любым другим цветом заливки не группируются и выступают границами между группами.

Важно: группируются только последовательные строки. Если между белыми строками находится строка другого цвета, необходимо завершить текущую группировку и начать новую при следующем появлении белой строки.

## 3. Алгоритм выполнения

После вставки subreport:

1. Определить фактический диапазон вставленных данных:
   - первая строка: `paste_row`;
   - последняя строка: `paste_row + height - 1`;
   - проверяемый столбец: `paste_col + group_rows - 1`.

2. Последовательно пройти по ячейкам проверяемого столбца сверху вниз, от первой строки вставленного диапазона до последней.

3. Для каждой ячейки определить цвет заливки.

4. Если обнаружена белая ячейка или ячейка без заливки:
   - если группировка еще не началась, запомнить текущую строку как начало группы;
   - продолжить движение вниз, пока встречаются группируемые ячейки.

5. Если обнаружена ячейка с другим цветом:
   - если до этого была обнаружена последовательность группируемых строк, закрыть группу на предыдущей строке;
   - выполнить группировку строк Excel от начала до конца найденного диапазона включительно;
   - сбросить состояние текущей группы;
   - продолжить проверку со следующей строки.

6. Если достигнут конец вставленного диапазона, но группировка еще открыта:
   - закрыть последнюю группу на последней строке диапазона;
   - выполнить группировку строк Excel от начала до конца группы включительно.

7. Перейти к следующему subreport из `data_files` и повторить алгоритм независимо от предыдущего subreport.

## 4. Важные ограничения

- Группировка выполняется только внутри текущего вставленного диапазона.
- Нельзя группировать строки за пределами границ subreport.
- Нельзя объединять группы из разных subreport, даже если они расположены рядом и имеют одинаковый цвет.
- Цветные строки не должны попадать внутрь группировки.
- Каждая непрерывная последовательность белых строк должна становиться отдельной группой Excel.
- Необходимо корректно обработать ситуацию, когда последовательность группируемых строк находится в самом начале или в самом конце вставленного диапазона.
- Если группируемая последовательность состоит из одной строки, она также считается отдельным диапазоном для группировки.
- Если `group_rows` не задан, не является допустимым числом или выходит за пределы `width`, группировку для данного subreport не выполнять. Необходимо обработать такую ситуацию без аварийного завершения всего процесса.

## 5. Ожидаемый результат

В результате после вставки каждого subreport в Excel должны создаваться группы строк по следующему правилу:

**Все расположенные подряд строки, у которых ячейки в столбце `group_rows` имеют белую заливку или заливка отсутствует, объединяются в одну группу Excel.**

Любая строка с другим цветом заливки завершает текущую группу и не включается в нее.

Группировка должна выполняться стандартным механизмом группировки строк Excel (Outline / Rows.Group), чтобы пользователь мог сворачивать и разворачивать полученные группы.

# Корректировка алгоритма вставки при `insert_rows = TRUE`

Необходимо изменить существующий алгоритм вставки данных при `insert_rows = TRUE`.

## 1. Новый алгоритм

Строка с номером `paste_row` используется как образец для создания строк под вставляемый диапазон.

Последовательность действий:

**Шаг 1. Копирование строки-образца**

Скопировать строку целевого листа с номером `paste_row`.

Эта строка содержит форматирование и другие необходимые свойства, которые должны быть перенесены на новые строки.

**Шаг 2. Создание пространства для данных**

Вставить скопированную строку в количестве, соответствующем высоте вставляемого диапазона минус 1 (т.к. учитываем имеющуюся среднюю строку).

Высота определяется по фактическому размеру snapshot:

`H = snapshot.Rows.Count` - 1

Новые строки должны располагаться начиная с `paste_row`.

Исходная строка `paste_row` и остальные строки листа должны сохраняться, смещаясь вниз.

**Шаг 3. Вставка данных**

В созданное пространство вставить исходный диапазон `snapshot`.

Координаты вставки:
- строка: `paste_row`;
- столбец: `paste_col`;
- высота: `snapshot.Rows.Count`;
- ширина: `snapshot.Columns.Count`.

Способ вставки определяется параметром `only_values`:
- `TRUE` — вставлять только значения, сохраняя форматирование созданных строк;
- `FALSE` — вставлять значения и форматирование исходного диапазона согласно существующему механизму.
